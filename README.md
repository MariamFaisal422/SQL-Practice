# Advanced SQL Server Lab — ITI

## Overview

This repository contains SQL queries developed as part of ITI training using the ITI database.

The exercises focus on querying and analyzing relational data related to students, instructors, departments, courses, and topics.

## Topics Covered

* Aggregate Functions: `COUNT()`, `MAX()`, `MIN()`, `AVG()`
* Joins and filtering
* Subqueries
* Handling NULL values using `ISNULL()` and `COALESCE()`
* Creating and querying Views
* Retrieving and filtering relational data

## Database

* **Database:** ITI
* **Environment:** SQL Server Management Studio (SSMS)

The database is not included in this repository. The SQL queries require access to the ITI database to run successfully.
